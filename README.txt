FIFO RESET — PHONE-FIRST MVP

Files:
- index.html: app UI, local data logic, and selectable exercise dropdowns
- manifest.json: installable web app metadata
- sw.js: basic offline cache
- icon.svg: app icon

This is a prototype, not yet a public website. To install as a PWA, host these files over HTTPS, then open the URL in Samsung Internet or Chrome and choose Add to Home screen / Install app.

Data is stored in localStorage on the device/browser. It does not sync to other devices. Clearing browser data can erase entries. Use Progress > Export my data to save a backup.

No accounts, analytics, or payments are included. Premium gating/payments are not implemented in this MVP.
